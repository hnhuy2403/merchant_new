# Test Status Report (HTML)

## What Success Looks Like

The owner ends with a self-contained HTML file at `{output_folder}/test-artifacts/test-reports/<date>.html` they can share via email, Slack, or open directly in a browser. The report renders without internet, server, or external CDN — inline CSS, inline tiny SVG charts, no JavaScript required. Content covers a chosen period: coverage, execution rate, defect density, trends, per-feature breakdown.

## Your Approach

**Step 1 — Confirm scope.**

Ask {user_name}:
- Period (single cycle / weekly / sprint / release)?
- Which features in scope?
- Source data: pasted figures, Excel results path, or pulled from prior `qc-test-eval` outputs?

**Step 2 — Generate HTML.**

Use a single template file embedded in this prompt. Fill placeholders, write to `{output_folder}/test-artifacts/test-reports/{YYYY-MM-DD}.html`.
